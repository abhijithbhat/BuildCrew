## App Title
BuildCrew: Contribution Ledger

## Short Description
Log your contributions, get teammates to confirm them, and share a link that shows GitHub activity and who vouched for what.

## Full Description
BuildCrew helps student and open-source software teams track authentic engineering impact.

Log your contributions, get teammates to confirm them, and share a link that shows GitHub activity and who vouched for what.

### Key Features
- **Log Contributions**: Record code, design, devops, and docs deliverables with attached evidence files and repository activity.
- **Peer Confirmation**: Teammates review and confirm deliverables so credit is clear, transparent, and agreed upon.
- **Connected Repositories**: Link your GitHub repository to import commits and pull requests while keeping unshared activity private until you choose to publish.
- **Public Passport**: Share a verified profile link displaying your confirmed contributions, associated repository work, and teammate confirmations.
- **Team Governance**: Establish team roles, resolve disputes collaboratively, and maintain an authentic project ledger.

### Data & Privacy
BuildCrew prioritizes developer control and data privacy. Attached evidence files are stored with links anyone with the link can open, and GitHub activity remains private until you explicitly choose to publish it to your public passport.
